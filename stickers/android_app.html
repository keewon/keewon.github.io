개인정보

계정도 로그인도 없고, 이름·전화번호 같은 개인 식별 정보를 수집하지 않습니다. 누구에게 보냈는지도 앱은 알지 못합니다. 앱이 얼마나 쓰이는지와 어떤 스티커가 인기 있는지는 익명 통계로 수집합니다. 화면 위쪽에 배너 광고가 있지만 광고 ID는 쓰지 않으며, 맞춤 광고가 아닌 전체 이용가 광고만 표시됩니다.

수집 항목 자세히 보기

기기 안에만 남는 것

  • 최근 보낸 스티커 최대 24개
  • 마지막으로 열었던 탭
  • 스티커를 보낼 때 앱 캐시에 잠시 복사되는 이미지

사용 통계 (Firebase Analytics)

  • 앱 인스턴스 ID — 설치할 때 만들어지는 무작위 값. 개인을 가리키지 않으며 앱을 지우면 사라집니다
  • 기기 모델, 안드로이드 버전, 앱 버전, 언어 설정
  • IP에서 추정한 대략적인 지역 (국가·지역 수준)
  • 실행 횟수, 사용 시간
  • 보낸 스티커의 팩과 파일명

광고 (Google AdMob)

  • 광고 ID(AAID)는 쓰지 않습니다 — 어린이를 포함한 이용자를 대상으로 하는 앱이라 접근 권한 자체를 제거했습니다
  • IP 주소와 그로부터 추정한 대략적인 지역
  • 기기 모델, 안드로이드 버전, 화면 크기
  • 광고가 표시된 횟수, 눌린 횟수

수집하지 않는 것

  • 이름, 나이, 성별, 전화번호, 주소, 연락처, 사진, 정밀 위치
  • 누구에게 보냈는지 — 안드로이드 공유 시트를 거치므로 앱은 알지 못합니다
  • 계정 정보 — 로그인 기능 자체가 없습니다
